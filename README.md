# Cameraman Battle

Telegram Mini App для коллекции Cameraman Tower Defense: кейсы, апгрейдер, инвентарь, обменник, ручное пополнение и выдача по наличию. Node.js 24+, SQLite, без npm-зависимостей.

Бот: https://t.me/cameraman_battle_bot · Новости: https://t.me/cameraman_battle

Интерфейс использует исходную вёрстку и анимации Brainrot Rush с тёмной синей темой Cameraman Battle. Логотип, маскот Titan Cameraman, аватар, игровая монета и девять иконок кейсов нарисованы отдельно. Галерея и PNG для скачивания: `/brand.html`. Промпты и описание: `ARTWORK.md`.

## Запуск на BotHost

1. Подключи этот репозиторий. Выбери сборку через Dockerfile, среду Node.js, а не Python.
2. Укажи переменные из `.env.example`: `BOT_TOKEN` нового бота, `PUBLIC_URL` с HTTPS, `ADMIN_ID=8911524524`. Токен хранится только в переменных хостинга.
3. Выдели постоянный диск на `/app/data`. База: `DATABASE_PATH=/app/data/cameraman.db`. Нужна новая база, перенос базы Brainrot Rush запрещён.
4. `DEV_MODE=0`. Порт 3000. Проверка доступности: `/health`.
5. Добавь бота администратором @cameraman_battle для проверки подписки.
6. Пересобери контейнер. Открой приложение в новом боте. В меню «Управление» укажи наличие и открой приём пополнений.

Команда запуска: `npm start`. Docker запускает `node server/index.js` автоматически. Новые изменения требуют пересборки контейнера.

## Локально

PowerShell: `$env:DEV_MODE='1'; $env:BOT_TOKEN=''; $env:PORT='3020'; npm start`

Открой http://127.0.0.1:3020. Без Telegram локально используется владелец; `?user=12345` переключает тестового игрока. В production этот режим запрещён.

## Правила

- 41 предмет. Диапазоны цены заменены средними, 1K = 1000 монет. `asset-map.json` фиксирует соответствие картинок из загрузок.
- Принимаются все предметы каталога. При подтверждении пополнения монеты начисляются по зафиксированной цене заявки, запас увеличивается.
- Обменник и покупка предлагают предметы из наличия. Наличие не резервируется покупкой/обменом; резерв создаётся при записи на выдачу, поэтому финальная доступность проверяется повторно.
- Выдача до пяти предметов, только при пополнении за последние 48 часов. Каждый день 19:30–20:00 МСК, слоты по 2 минуты, вход подтверждается в первую минуту. Если день заполнен — следующий день.
- Владелец включает выдачу до 19:30; без включения заявки возвращаются в инвентарь с уведомлением. При пропуске слота предметы возвращаются также.
- Stars и розыгрыша нет. Из игр только кейсы и апгрейдер. Маржа апгрейдера 8%, шанс до 75%.
- Шесть платных кейсов со стартовым расчётным RTP 90%. Это средний возврат по стоимости каталога, не обещание дохода проекта. Два бесплатных кейса каждые 6 часов (EV по 7 монет), реферальный однократный. Учти расходы бесплатных наград, кэшбэка и партнёров.
- Админка: пополнения/выдача, сток, цены и состав кейсов, игроки/блокировки/балансы, партнёры, промокоды, экономика, журнал, постоянный режим обновления.
- Честность: SHA-256 коммит перед раундом, HMAC-SHA256 по seed и nonce. В профиле доступна клиентская проверка закрытых раундов.

## Проверка и резервные копии

`npm test` · `npm run audit:economy`

Для резервной копии используй `node server/backup.js`, хранить копии отдельно от сервера. Перед публичным запуском проверь новый Telegram-токен, HTTPS, проверку подписки, реальные трейды, сохранение базы после перезапуска и восстановление из копии.
